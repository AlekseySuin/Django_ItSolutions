# Система учета транзакций
веб-приложение, которое позволяет пользователям создавать, редактировать, удалять и просматривать записи о движении денежных средств.

# Как запустить проект?
## 1. Клонируйте проект
```
git clone https://github.com/AlekseySuin/Django_ItSolutions
```
cd ваш-репозиторий
## 2. Запуск с помощью встроенного сервера
Переходим в директорию проекта (myproject)
```
cd myproject
```
И запускаем сервер
```
python manage.py runserver
```
Сервер будет доступен по адресу:
```
http://127.0.0.1:8000/
```
